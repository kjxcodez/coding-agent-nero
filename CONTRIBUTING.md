# Contributing to NERO

Thank you for your interest in contributing to NERO (Evolution Edition)! Contributions of all kinds are highly welcome.

## How to Contribute
1. Fork the repository.
2. Create a new feature or bugfix branch: `git checkout -b feature/my-cool-idea`.
3. Implement your changes and write unit tests.
4. Ensure all unit tests pass: `python -m pytest tests/`.
5. Submit a Pull Request!
